# Bead Studio Plan 2：網頁 UI 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. UI tasks (Task 6 起) 的實作者必須先載入 `frontend-design:frontend-design` skill。

**Goal:** 在 Plan 1 的伺服器上加上網頁 UI：平面編輯、分格豆盒色票、即時用量與檢查、3D 實體預覽、配色版本、庫存管理與校色、拖曳導入、匯出，並與 AI（MCP）的修改即時同步。

**Architecture:** 伺服器新增三個介面：`GET /api/state`（完整狀態快照）、`POST /api/tools/:name`（把 UI 的指令轉給「同一個進程內的 MCP server」，與 AI 走完全相同的程式碼）、`/ws`（只廣播狀態變更）。另有 `POST /api/import` 接收上傳圖片。前端 `src/web/` 以 Vite + React 撰寫，直接 import `src/core/` 的純函式（繪圖、檢查、配色、op 套用預覽）。所有修改都由伺服器套用，前端只做樂觀預覽。

**Tech Stack:** React 19、Vite 8、@vitejs/plugin-react、@fastify/websocket、@fastify/static、ws（測試用）、@playwright/test、concurrently；字體 jf 粉圓 Huninn（Google Fonts）。

**Spec:** `docs/superpowers/specs/2026-11-11-bead-studio-design.md`（§5 UI、§6 匯出導入、§10 錯誤處理、§11 測試）
**視覺參考（已與使用者確認）：** `docs/superpowers/mockups/layout-v4.html`（版面與互動）、`docs/superpowers/mockups/visual-style-v2.html`（豆子渲染）

## Global Constraints

- 視覺：A「奶油手作」UI + B 霧面圓柱豆；編輯區純平面，3D 只用於實體預覽
- 色票的唯一亮點：「分格豆盒」——半透明分格收納盒，每格裝幾顆霧面豆，格底標色號與剩餘顆數；庫存越少豆越少，沒有的顏色是空格。其他元件保持安靜、樸素
- 設計 tokens（`src/web/styles/tokens.css`，任何元件不得寫死其他色碼）：`--paper #F6EEDF`、`--ink #4A3A2E`、`--ink-soft #725D4E`、`--board #EADBC4`、`--peg #D9C6A6`、`--peach #E8A87C`（只用於「選取中」）、`--alert #B5402F`（警告、不足）、`--card #FFFDF8`
- 字體：全站 `"Huninn", "PingFang TC", "Noto Sans TC", sans-serif`；數字用 `font-variant-numeric: tabular-nums`
- 文案：繁體中文、句子式、動詞開頭的按鈕（「匯出圖片」不是「確定」）；不用全大寫標籤、不在按鈕加 `→`
- 所有修改走 `POST /api/tools/:name`（與 MCP 相同）；UI 不得自行寫入伺服器狀態
- 伺服器的 Host/Origin 檢查不得放寬；開發模式以 `BEADS_ALLOWED_HOSTS=localhost:5173` 允許 Vite dev server
- 動態：只有編輯區的豆子跳動（Task 8）是刻意的動畫亮點；其他元件不加裝飾性進場動畫
- 亮暗模式（Task 16）：所有顏色走 tokens，豆子顏色不隨主題改變；Task 16 之後的 UI task 要在亮、暗兩種模式各截圖檢查
- 可存取性底線：鍵盤可操作、可見 focus、`prefers-reduced-motion` 時關閉動畫、桌面寬度 ≥ 1100px 為主要目標，窄於 900px 時右側面板改為下方
- 每個 task 結束 `pnpm test` 與 `pnpm typecheck` 全綠並 commit；commit 結尾加 attribution trailer

## Review Focus

1. **AI 改圖時使用者正在畫**：預期使用者畫的那一筆不遺失、畫面最後與伺服器一致。→ Task 5 測試 `server state supersedes optimistic preview by version`
2. **伺服器斷線**：預期畫面顯示「離線」、停用編輯，重連後自動抓最新狀態（spec §10）。→ Task 4 測試 `reconnects and refetches state`、Task 6 Playwright
3. **拖入的 PNG metadata 損毀**：預期退回一般圖片轉換並提示，不是空白錯誤。→ Task 2 測試 `import endpoint falls back with notice`
4. **改面板尺寸會裁掉豆子**：預期 UI 先確認，確認後才帶 `force: true`；鎖定時直接顯示原因。→ Task 12 測試 `crop asks for confirmation`
5. **長筆畫超過 500 格**：預期一筆仍是一個 undo 步驟、不因指令數上限失敗。→ Task 7 測試 `strokeToPaste emits a single paste op`
6. **自己畫的那一筆被伺服器回聲時又跳一次**：預期只在畫的當下跳一次。→ Task 8 的 echo 標記與 e2e

```ts
import { Client } from '@modelcontextprotocol/sdk/client/index.js';
import { InMemoryTransport } from '@modelcontextprotocol/sdk/inMemory.js';
import { buildMcpServer, type Vision } from './mcp';
import type { PathOpts } from './paths';
import type { DesignStore } from './store';

export type ToolResult = { ok: boolean; text: string; images: { data: string; mimeType: string }[] };

export async function createToolClient(store: DesignStore, opts: { vision?: Vision } & PathOpts) {
  const server = buildMcpServer(store, { ...opts, vision: opts.vision === 'off' ? 'on' : opts.vision });
  const [ct, st] = InMemoryTransport.createLinkedPair();
  await server.connect(st);
  const client = new Client({ name: 'bead-studio-web', version: '1.0.0' });
  await client.connect(ct);
  return {
    async call(name: string, args: Record<string, unknown>): Promise<ToolResult> {
      try {
        const r: any = await client.callTool({ name, arguments: args });
        const content: any[] = r.content ?? [];
        return {
          ok: !r.isError,
          text: content.filter((c) => c.type === 'text').map((c) => c.text).join('\n'),
          images: content.filter((c) => c.type === 'image').map((c) => ({ data: c.data, mimeType: c.mimeType })),
        };
      } catch (e) {
        return { ok: false, text: (e as Error).message, images: [] };
      }
    },
    async close() { await client.close(); await server.close(); },
  };
}
```

```ts
  setCalibration(code: string, hex: string | null): void {
    if (!this.palette.has(code)) throw new OpError('unknown_color', `未知色號 ${code}`);
    if (hex !== null && !/^#[0-9A-Fa-f]{6}$/.test(hex)) throw new OpError('bad_hex', `色碼格式錯誤：${hex}（例如 #E8434F）`);
    const path = join(this.opts.dataDir, 'palette.json');
    const colors: PaletteColor[] = JSON.parse(readFileSync(path, 'utf8'));
    const c = colors.find((x) => x.code === code)!;
    if (hex === null) delete c.calibratedHex; else c.calibratedHex = hex.toUpperCase();
    writeJsonAtomic(path, colors);
    this.palette = new Palette(colors);
    this.paletteColors = colors;
    this.emit('meta');
  }
```

```ts
/** 波浪排程：以「改變格子中最左上那格」為起點，沿對角線往右下傳遞；延遲 = (dx + dy) × stepMs，整段最長 maxMs（超過時等比例壓縮） */
export function waveDelays(cells: number[], cols: number, o?: { stepMs?: number; maxMs?: number }): Map<number, number>
/** 跳動曲線：t ∈ [0,1] → 縮放倍率；0→1 時先縮到 0.82、彈到 1.12、回到 1（帶一點過衝），t≥1 為 1 */
export function bounceScale(t: number): number
export const BOUNCE_MS = 280;
```
